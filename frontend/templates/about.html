Sobre o Sistema

Sistema de gerenciamento de alunos desenvolvido com arquitetura de microsserviços, separando frontend e backend em containers Docker independentes.

  • Backend FastAPI + PostgreSQL
  • Frontend Flask + Jinja2
  • Infra Docker Compose
  • Testes Pytest + HTTPX

Funcionalidades

  • Cadastro de alunos com geração automática de ID por curso
  • Listagem, busca, edição e remoção de alunos
  • Suporte aos cursos: GES, GEC, GET e GEP
  • Middleware de logging e headers customizados
